# Luna Marouf — research portfolio

Source for **https://lunamarouf.github.io/research-portfolio/**

Static HTML, no build step. Open `index.html` to view locally.

```
index.html          landing page, work grouped by category
awards.html          full awards list
publications.html    full publications and presentations list
research/            lab research, one page per sensor/lab project
  sensors-cytochrome-c.html      ACuTE — cytochrome c straight-channel sensor
  sensors-envelope2.html         ACuTE — Envelope 2 / HCV circular device (active)
  sensors-lps-lta.html           ACuTE — LPS/LTA endotoxin sensor
  membranes-air-filtration.html  Freire-Gormaly — chitosan:PVA electrospun membranes
  membranes-ro-antifouling.html  Freire-Gormaly — RO anti-fouling coatings
  tribology-graphene.html        Freire-Gormaly — graphene coating wear resistance
projects/            course design projects, one page per project
clubs/                club and competition work, one page per club
personal/             personal projects outside of school or lab
assets/site.css      shared stylesheet
assets/              figures
```

The analysis code linked from the sensor pages lives in
[electrochemical-biosensor-analysis](https://github.com/LunaMarouf/electrochemical-biosensor-analysis).

Several pages are skeletons pending source material (photos, data, CAD, code) — marked with a
`.note` callout at the point where content is still needed.
